Monad mainnet · chain 143

Conviction, with receipts.

Stance is a Monad-native conviction market for publishing thesis-backed Stances, taking Back or Fade positions, trailing public portfolios, and building a permanent Said vs Did record.

Core product

Stances

Publish a clear thesis, a side, resolution criteria and optional on-chain proof.

Proof Stances

Attach wallet activity and position targets so conviction can be checked against behavior.

Trail Portfolios

Build an attributed portfolio plan from another caller's public allocation without copying custody.

Receipts

Track calibration, performance, exits, liquidation history and Said vs Did integrity.

Live integration status

Monad: live RPC and deployed Stance contracts on chain ID 143.
Privy and Mera: embedded sign-in plus passkey-derived Trading, Proof and Trail accounts.
Agora: live AUSD balance reads for the connected Monad wallet.
Kuru: wallet-bound quote and transaction planning endpoints are connected.
Envio: Monad event indexing and position tracking are configured.
Perpl account analytics: awaiting production-origin whitelisting by Perpl. Public Monad context remains available.
Real-money execution: intentionally safety-locked until the contracts, wallet policies, routing and monitoring pass final review.

Safety model

Stance never asks the server to hold a user key. Live transactions must be simulated, checked for Monad chain ID and wallet ownership, then signed in the connected wallet. Demo balances and Play points are explicitly separate from on-chain assets.
